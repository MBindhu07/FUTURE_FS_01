# FUTURE_FS_01 — Personal Professional Portfolio Website

This project is built for **Future Interns — Full Stack Web Development, Task 1**.

## Task requirements covered

- Personal professional portfolio
- Interactive sections for profile, skills and projects
- Responsive design
- Contact form UI
- SEO-friendly HTML metadata
- React.js frontend
- GitHub-ready source code
- Deployment-ready Vite build

The internship brief recommends React.js for the frontend and lists an interactive resume/portfolio, contact form with email notifications and SEO-friendly structure as key features.

## Tech stack

- React.js
- Vite
- HTML5
- CSS3
- JavaScript

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview
```

## Before submitting

Replace these placeholders in `src/main.jsx`:

- `your-email@example.com`
- GitHub profile URL
- LinkedIn profile URL
- Project live links

### Contact email notifications

The current form provides the complete frontend interaction. To meet the email-notification requirement for a real deployment, connect the form to a service such as EmailJS, Formspree or Web3Forms, or connect it to your own Node.js backend.

Do not put private API keys directly in source code.

## Resume

If you want the Resume button to work, place your PDF at:

```text
public/resume.pdf
```
